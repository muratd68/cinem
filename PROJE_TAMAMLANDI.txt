PROJE ÖZETİ
===============================================================================

CineMAX, Next.js 14 ile geliştirilmiş modern bir sinema bilet satış frontend
uygulamasıdır.

Özellikler:
- Film listeleme, arama ve filtreleme
- Koltuk seçimi sistemi
- Ödeme sayfası (form validasyonu)
- Admin paneli (film CRUD işlemleri)
- Çoklu dil desteği (TR/EN)
- QR kodlu biletler
- Favoriler sistemi
- Sinema bulucu (konum tabanlı)
- Dark/Light tema
- Toast bildirimleri
- Bilet geçmişi
- Kupon/indirim sistemi

Teknolojiler:
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React Icons
- React Context API
